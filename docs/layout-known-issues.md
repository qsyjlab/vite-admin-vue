# Layout 已知问题

## 折叠菜单子项选中后出现空白高亮块

- 状态：已记录，延后处理
- 优先级：P1
- 发现日期：2026-07-11
- 当前策略：不阻塞 ProComponents 开发，在 `ProField` 阶段完成后回到 Layout 集中修复

### 复现步骤

1. 使用左侧菜单布局并折叠侧边栏。
2. 点击包含子菜单的一级菜单，打开浮层菜单。
3. 选择一个叶子菜单，例如 `ProCheckboxGroup`。
4. 再次查看该一级菜单的浮层。

### 实际结果

- 当前叶子菜单可以正确显示选中背景。
- 选中项下方出现一块没有文字和图标的浅色空白区域。
- 深色导航下空白区域对比明显，会被误认为额外的可点击菜单项。

### 期望结果

- 浮层高度只由实际菜单项和配置的间距决定。
- 选中背景只作用于当前菜单项。
- 不产生空白菜单项、残留高亮或额外占位高度。

### 后续排查范围

- Element Plus 折叠菜单 Teleport 浮层中的 active 状态 DOM。
- `.el-menu--popup`、`.menu-popper-wrapper` 和 `.is-menu-popup` 的高度、padding 与背景覆盖。
- 菜单浮层滚动容器或伪元素是否在路由切换后保留占位。
- 浅色应用配合深色导航时的覆盖变量是否错误作用于空容器。

### 验收场景

- 左侧菜单、顶部菜单、顶部混合、左侧混合四种布局。
- 展开与折叠侧边栏。
- 浅色导航、深色导航和应用暗色模式。
- 一级菜单、二级菜单和三级菜单选中状态。
